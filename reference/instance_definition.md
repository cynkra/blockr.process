# The definition an instance was opened with

The definition an instance was opened with

## Usage

``` r
instance_definition(store = ".runs", instance = "instance")
```

## Arguments

- store:

  Store directory.

- instance:

  Instance id to filter by, or \`NULL\` for all instances.

## Value

The wide process table as stamped by \[start_instance()\], or \`NULL\`
if the instance has not been opened.
